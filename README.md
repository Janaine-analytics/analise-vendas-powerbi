# Análise de Vendas com Power BI

## Sobre o projeto

Este projeto tem como objetivo analisar dados de vendas de uma loja fictícia, utilizando análise de dados para transformar informações em indicadores que apoiem a tomada de decisão.

O projeto será desenvolvido como parte dos meus estudos práticos em Análise de Dados e Business Intelligence.

## Objetivos

- Analisar o faturamento total.
- Identificar os produtos mais vendidos.
- Comparar o desempenho das categorias de produtos.
- Avaliar a evolução das vendas ao longo do tempo.
- Desenvolver indicadores para apoiar decisões de negócio.

## Ferramentas e tecnologias

- GitHub: organização e documentação do projeto.
- SQL: consultas e análise de dados.
- Power BI: visualização de dados e construção de dashboards.
- Excel ou CSV: organização inicial dos dados.

## Etapas do projeto

1. Definir e conhecer a base de dados.
2. Explorar e tratar os dados.
3. Realizar análises e calcular indicadores.
4. Construir um dashboard no Power BI.
5. Documentar os resultados e as conclusões.
